The Nilgiris ambulance reference is a source link, not a calling integration. Community practice cards are labelled as proposed programme practices where applicable. Confirm local pathways, source permissions, medical wording and Tamil meaning before a pilot. Every card needs named clinical/language reviewers and a review-by date in the agreed publication process.

The complete bilingual text, tags, approval fields and reuse notes live in [`data/knowledge.json`](../data/knowledge.json). Expired cards are excluded; approved draft release rechecks source versions and expiry. See [architecture](architecture.md) and [the roadmap](../ROADMAP.md).
